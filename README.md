# CPS Services and Support

A responsive website for CPS equipment repair and service support.

## Getting started

Install dependencies:

```bash
npm install
```

Start the local development server:

```bash
npm start
```

Create a production build in `dist/`:

```bash
npm run build
```

Deploy the production build to GitHub Pages:

```bash
npm run deploy
```
